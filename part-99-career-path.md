## 99.1 Android Developer Career Levels

```
Junior Android Developer (0-2 ปี):
- เขียน Activity, Fragment ได้
- ใช้ RecyclerView, Retrofit, Room ได้
- เข้าใจ MVVM พื้นฐาน
- ใช้ Git ได้
- debug ด้วย Logcat ได้
เงินเดือน (ไทย): 25,000-45,000 บาท

Mid-Level Android Developer (2-5 ปี):
- เขียน Clean Architecture ได้
- ใช้ Hilt DI ได้
- ทำ Unit Test ได้
- เข้าใจ performance optimization
- ทำ multi-module project ได้
- CI/CD pipeline ได้
เงินเดือน (ไทย): 50,000-90,000 บาท

Senior Android Developer (5+ ปี):
- ออกแบบ architecture ของ project ได้
- mentor junior/mid developers ได้
- ทำ technical decision ได้
- เข้าใจ security deeply
- เขียน SDK/library ได้
- ทำ code review อย่างมีประสิทธิภาพ
เงินเดือน (ไทย): 100,000-200,000+ บาท

Tech Lead / Principal:
- กำหนด technical direction
- ทำงานร่วมกับ Product/Design
- ทำ feasibility study
- สร้าง engineering culture
เงินเดือน (ไทย): 150,000-300,000+ บาท

Remote / Freelance (US/EU companies):
- Senior → $80,000-$150,000/year
- ต้องมี English proficiency
- portfolio ที่แข็งแกร่ง
```

## 99.3 Open Source Contribution

```
Step 1: Start with documentation
- แก้ typo, เพิ่ม example
- แปล documentation เป็นภาษาไทย
- ไม่ต้องเขียน code ก็ contribute ได้

Step 2: Fix easy bugs
- หา issues ที่ label: "good first issue" หรือ "beginner friendly"
- Popular Android repos:
  * coil-kt/coil
  * square/retrofit
  * bumptech/glide
  * InsertKoinIO/koin
  * cashapp/sqldelight

Step 3: Add features
- เปิด issue อธิบาย feature ก่อน
- รอ maintainer approve
- Fork → branch → code → PR

Step 4: Maintain your own library
- สร้าง utility library ที่คุณใช้เอง
- Publish ไป Maven Central หรือ JitPack
- ช่วย build credibility ใน community
```

## 99.5 Salary Negotiation Tips

```
1. รู้ market rate:
   - levels.fyi (global)
   - glassdoor.com
   - LinkedIn Salary
   - ถามเพื่อนในวงการตรงๆ

2. เตรียม portfolio:
   - GitHub ที่ active
   - Apps บน Play Store (ถ้ามี)
   - Blog/Medium articles
   - Open source contributions

3. Interview preparation:
   Data Structures & Algorithms:
   - LeetCode: Easy 50 ข้อ, Medium 30 ข้อ
   - focus: Array, String, HashMap, Tree, Graph

   Android-specific:
   - Activity/Fragment lifecycle
   - ความแตกต่าง: Handler vs AsyncTask vs Coroutine
   - MVVM vs MVP
   - RecyclerView internals
   - Memory leaks (causes + fixes)
   - App startup optimization
   - ART vs Dalvik

   Behavioral (STAR format):
   - "เล่าประสบการณ์แก้ bug ที่ยากที่สุด"
   - "ทำงานกับ deadline ที่ tight อย่างไร"
   - "conflict กับ teammate แก้อย่างไร"

4. Negotiation:
   - อย่ารีบบอก expected salary ก่อน
   - ให้ HR เสนอมาก่อน
   - เปรียบเทียบ total package (ไม่ใช่แค่ base)
   - Remote work = leverage ใหญ่มาก
```
